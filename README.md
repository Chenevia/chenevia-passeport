# Chenevia — page publique des sachets

Page ouverte par le QR code des étiquettes Chenevia (`https://id.chenevia.com/s/<sachet>`).

Page statique : elle ne lit que les informations publiques des sachets (variété, poids,
année de culture, dates du parcours), publiées par Chenevia. Aucune donnée interne ici.

Source : dépôt privé Chenevia/chenevia-stocks, dossier `page-publique/`.
